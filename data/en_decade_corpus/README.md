# Decade Sub-Corpora and Corpus Metadata

This directory contains the decade-level text files used for all analyses in the paper, along with corpus metadata CSVs extracted from the HMD and LwM XML metadata files.

The text files (`en_*.txt`) are too large to host on GitHub and must be generated locally — see `corpus_preparation/` for instructions. The metadata CSVs are included in the repository.

## Directory Structure

```
en_decade_corpus/
├── README.md
├── corpus_overview.csv                     # Per-decade corpus composition statistics
├── newspaper_inventory.csv                 # All 120 newspaper titles in the corpus
├── top30_newspapers_by_article_count.csv   # Top 30 newspapers by volume
├── en_1800s.txt                            # Not in repo — generated locally
├── en_1810s.txt
├── ...
├── en_1910s.txt
├── aggregation_report.txt                  # Generated by aggregate_and_partition.py
└── aggregation_stats.json                  # Generated by aggregate_and_partition.py
```

## Corpus Metadata Files

### `corpus_overview.csv`

Per-decade summary of the corpus composition. Generated by `corpus_preparation/extract_corpus_metadata.py`.

| Column | Description |
|---|---|
| `Decade` | Decade label (e.g., `1800s`) |
| `Articles` | Total number of articles |
| `Words` | Total word count (from XML metadata) |
| `HMD` | Number of articles from Heritage Made Digital |
| `LwM` | Number of articles from Living with Machines |
| `Papers` | Number of distinct newspaper titles active in this decade |
| `London_percent` | Percentage of articles from London-based newspapers |
| `OCR_mean` | Mean OCR confidence score (0–1) across all articles |
| `OCR_median` | Median OCR confidence score |

### `newspaper_inventory.csv`

Complete inventory of all 120 newspaper titles in the corpus.

| Column | Description |
|---|---|
| `BL_ID` | British Library identifier |
| `Newspaper_Title` | Title as it appears in the metadata |
| `Location` | Publication location |
| `Collection` | Source collection: `HMD` or `LwM` |
| `Articles` | Total number of articles from this title |

The corpus comprises 17 London-based titles (2,530,729 articles, predominantly HMD) and 103 provincial titles (6,795,441 articles, predominantly LwM). For normalised title names and full documentation, see [Ridge and Pedrazzini (2024)](https://livingwithmachines.ac.uk/public-domain-newspaper-titles-in-living-with-machines/).

### `top30_newspapers_by_article_count.csv`

The 30 largest newspapers by article count, with BL ID, collection, location, and title. The largest single contributor is *The Sun* (BL ID 0002194, London, HMD) with 1,625,117 articles.

## Decade Text Files

One plain-text file per decade, each containing all articles from that decade concatenated with one article per line. These are the input to both the static embedding analysis (via the pretrained Word2Vec vectors) and the domain adaptation of MacBERTh.

**To generate these files**, follow the instructions in `corpus_preparation/README.md` or run:

```bash
python corpus_preparation/aggregate_and_partition.py \
    --lwm /path/to/lwm-alto2txt/plaintext \
    --hmd /path/to/hmd-alto2txt/plaintext \
    --output ./data/en_decade_corpus \
    --workers 4
```
